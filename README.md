# NEU-LIBRARY-VISITOR-LOG
A comprehensive web-based visitor management system for New Era University Library. This system allows visitors to check in/out, administrators to monitor visitor activity, and super admins to manage user roles.

### 👥 Visitor Features
- **Google OAuth Login** - Secure login using @neu.edu.ph Google accounts
- **Quick Check-in/Out** - Easy registration with department, program, and purpose
- **Profile Picture Support** - Automatically uses Google profile picture
- **Real-time Clock** - Philippine Time (PHT) display

### 🔐 Super Admin Features
- **User Role Management** - Assign admin or super_admin roles
- **Admin Requests** - Approve or reject admin applications
- **Full System Access** - All admin features plus user management
